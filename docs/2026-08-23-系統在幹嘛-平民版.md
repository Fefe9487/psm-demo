# 這套線上填報在幹嘛（說明用）

一句話：廠裡先把「哪條製程、哪台設備、哪種化學品」建成三本名冊。後面 PSM 十四項都從這三本勾選，不要每張表自己再打一套名字。

---

## 最精簡概念（可直接唸）

傳統 PSM 是「十四份文件齊了就算完成」：各單元自己寫化學品、設備、評估，名稱可以各寫各的，對得到對不到現場沒人一次查完。

這套系統改成「先有名冊、再填十四項」：製程、設備、化學品各建一張表，後面評估、程序、檢查、動火、應變都只能勾已有的編號。同一條管子、同一桶料，全廠一個叫法。系統可以提示該討論什麼，但不幫你評分、不自動停機。

核心差異就一句：傳統管的是「有沒有交那十四份」；這裡管的是「十四項是不是在講同一套現場」。

---

## 現在紙本常出什麼問題

同一條管子，這張表叫「酸液管」、評估表手打「鹽酸輸送」、設備清單又寫 PL-201。十四項都交得出去，對不到現場。改善、檢查、換料以後，也不知道要改哪一筆。

---

## 第一次進來，照這個順序填

1. 這家廠、這個甲類範圍、有哪些部門  
2. **製程**：這條線在做什麼（給一個製程編號）  
3. **設備**：現場位號（給一個設備編號；類型只能選一種，控制系統和緊急停車要分開）  
4. **化學品**：這條製程用到什麼（用 CAS 當代號；同一種料用在不同製程，就分兩筆）  
5. **對應表**：這台設備裡實際是哪種料、材質、會不會殘留  
6. 才做 **製程危害控制措施**（先選製程；節點只能選這條製程已經建好的設備和化學品）  
7. 其餘（操作程序、訓練、承攬、啟動前檢查、機械完整性、動火、變更、事故、應變、稽核…）全部勾前面的編號，不要另打名稱  

計畫、規章、圖檔可以上傳檔案，但圖號、版次、屬於哪條製程仍要填。只有檔、沒有編號，之後評估對不到。

---

## 系統會幫你什麼、不會幫你什麼

**會**

- 提醒：這台設備、這種料、這個條件，小組該討論什麼（例如碳鋼管線裝鹽酸、停車沒排乾）  
- 帶入安全資料表上的危害語句（GHS），火災、腐蝕、毒性方向先帶出來，人再確認  
- 機械完整性可連職安署「設備管線劣化機制查詢資料庫」當參考  

**不會**

- 不會幫你打嚴重度、可能性  
- 不會自動停機、不會自動結案  
- 劣化資料庫查出來的東西，不能拿來當風險分數  

---

## 跟法規怎麼講（有人問「這樣合法嗎」時）

甲類送審本來就要交《危險性工作場所審查及檢查辦法》附件一「安全衛生管理基本資料」，裡面就有化學品、危險性機械或設備、廠區配置。  
這套做法是：先把這三件事做成可勾選的名冊，PSM 十四項從名冊長出來。  
不是少交附件一，也不是把附件一十二項改寫成另外三張法定表。

---

## 用一個例子講完

製程：酸液輸送（P-ACID）  
設備：現場位號 PL-201，碳鋼管線  
化學品：氯化氫水溶液（CAS 7647-01-0）  
對應表寫：這條管子裡是鹽酸，可能殘留。  

之後評估、操作程序、檢查、動火、應變防護衣，都勾 PL-201 和這個化學品代號。不要再出現「酸液管」「鹽酸線」三種叫法。

## 跟計畫書、期中報告怎麼對

| 計畫在問的 | 白話 |
| --- | --- |
| 手冊 | 第一次填報時，十四項各要準備什麼、欄位怎麼掛編號 |
| 網站架構 | 先有三本名冊和填報順序，不是十四個互不相干的網頁 |
| 製程安全資訊 | 料、技術、設備、圖，都掛同一套編號 |
| 勞工參與 | 不能只丟一份計畫；紀錄要對到哪次評估、哪條製程 |
| 機械完整性 | 檢查的那台，就是名冊上那台；可查劣化，但不代評分 |
