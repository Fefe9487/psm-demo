# 4.5　擴充石化及化學工廠製程安全管理線上風險評估功能

本計畫期中已完成《石化及化學工廠製程安全管理線上風險評估參考手冊》草案，並與資訊公司討論網站基本架構及擬定線上填報格式；網站尚未擴充上線。製程安全資訊、勞工參與及機械完整性之填報規格已納入手冊，相關網站模組將於架構確立並完成座談後再行設計。

## 4.5.1　研擬「石化及化學工廠製程安全管理線上風險評估參考手冊」

已完成《石化及化學工廠製程安全管理線上風險評估參考手冊（草案）》。依《危險性工作場所審查及檢查辦法》第五條，甲類工作場所之審查申請應檢附附件一安全衛生管理基本資料，以及《製程安全評估定期實施辦法》第四條所定製程安全管理資料。本手冊以附件一為填報起點，參考其中危害性化學品管理、危險性機械或設備管理及工作場所配置所需資料，規劃製程、設備、化學品三張核心表，作為銜接製程安全管理十四項填報之共用索引。三張核心表係本計畫之資料整理方式，不取代附件一原列十二項及法定應檢附內容。送審應說明及應檢附事項仍以現行法令與本署審查要求為準。適用於石化、化學或半導體工廠之甲類危險性工作場所。

**表一　手冊草案章節一覽**

| 手冊章節 | 對應 | 內容 |
| --- | --- | --- |
| 第一章 | 總則 | 適用、欄位與附件、填報順序、系統提示 |
| 第二章 | 核心表格 | 製程、設備、化學品三張核心表；部門、圖資及緊急停車方案為附屬資料 |
| 第三章 | 審查辦法附件一 | 安全衛生管理基本資料；計畫類上傳 |
| 第四至十七章 | PSM 十四項 | 製程安全資訊至商業機密之第一次填報應備資料 |
| 第十八章 | 裝卸、輸送 | 有裝卸者之佔用紀錄 |
| 附錄一 | 一覽 | 應填表單與附件 |
| 附錄二 | 座談 | 討論綱要 |

第一次填報先完成與附件一相關之製程、設備、化學品三張核心表，作為後續填報之共用索引。系統得依既有資料提示應辦事項，不代填嚴重度與可能性。

**表二　製程、設備及化學品三張核心表**

## 4.5.2　擴充網站基礎架構，以確立製程安全管理資料數位化

已與資訊公司討論網站基本架構，並擬定線上填報格式。本期尚未擴充網站上線，下半年依座談後之功能規格辦理。設計構想如下。

網站規劃以《危險性工作場所審查及檢查辦法》附件一安全衛生管理基本資料為填報起點，將製程、設備、化學品規劃為共用索引，再銜接各項製程安全管理資料。此作法參考附件一所定危害性化學品管理、危險性機械或設備管理及工作場所配置所需資料，但不取代附件一原列十二項。以下美國職業安全衛生署（Occupational Safety and Health Administration [OSHA], n.d.）、美國化學工程師學會製程安全中心（Center for Chemical Process Safety [CCPS], 2007）、國際電工委員會（International Electrotechnical Commission [IEC], 2016）、全球化學品統一分類和標示制度（GHS）及美國石油協會（API）資料，僅作為資料架構與技術方法之對照，不作為我國法定填報依據。OSHA（n.d.）規定雇主應於實施製程危害分析前完成書面製程安全資訊之編纂，內容包括化學品危害、製程技術及製程設備；CCPS（2007）則將製程知識管理列為了解危害與風險之基礎，並強調資料應可取得且維持正確。

填報採引導式進行，順序如表四。計畫、規章、圖檔等以附件上傳並登錄名稱及日期；評估、存量、編號等須入欄位。《危險性工作場所審查及檢查辦法》第五條第二項規定，甲類工作場所之審查申請應登錄於中央主管機關指定之資訊網站；《製程安全評估定期實施辦法》第八條第二項另規定，定期製程安全評估報告應登錄於該網站。本署《小型企業製程安全管理實施指引》（勞動部職業安全衛生署，2019）指出書面製程安全資訊得以電子化方式保存；該指引適用於三十人以下之甲類工作場所，且屬行政指導，本文僅作數位保存方式之技術參考。網站因此規劃同時支援結構化欄位與電子檔。

同一製程之設備與化學品對應後，由規則引擎依既有資料提示應討論之偏離、不相容、引入前檢查及旁通。系統提示之設計參考 IEC 61882:2016 所述由小組就設計意圖偏離進行檢討的方法；嚴重度與可能性仍由評估小組填寫，不由程式代評。

化學品危害說明採用 GHS 危害聲明代碼（United Nations Economic Commission for Europe, 2023），並與《危害性化學品標示及通識規則》及國家標準 CNS 15030 之分類標示銜接。火災、腐蝕、毒性等方向由安全資料表帶入後確認，不再另建一套勾選表。裝卸不另設運輸表，車牌寫在佔用紀錄。

後續網站模組擬優先規劃製程安全資訊、勞工參與及機械完整性，實際功能依座談共識及後續系統功能規格辦理。本署既有「設備管線劣化機制查詢資料庫」得就材質、內容物及操作條件比對可能劣化機制；劣化機制之技術內容得參考 API 571（American Petroleum Institute, 2020），查詢結果不得代替製程危害控制措施之風險評分。

**表五　網站架構設計構想**

| 層次 | 設計想法 | 對應 |
| --- | --- | --- |
| 共用索引 | 以審查辦法附件一為填報起點，規劃製程、設備、化學品三張核心表 | 審查辦法附件一；OSHA 1910.119(d)（技術對照） |
| 銜接各項要求 | 製程安全管理十四項使用三張核心表之既有編號 | 製程安全資訊至商業機密 |
| 引導填報 | 建議依表四順序引導填報，評估前先完成三張核心表所需資料 | 表四 |
| 欄位與附件 | 編號、存量、評估入欄位；計畫、圖檔上傳並登錄圖號版次 | 審查辦法第五條登錄指定網站 |
| 評估 | 先選製程，再選該製程下設備及化學品；嚴重度與可能性由小組填 | IEC 61882 |
| 危害帶入 | 危害說明用 GHS H 代碼，自安全資料表帶入後確認 | 通識規則；CNS 15030 |
| 後續模組規劃 | 擬優先規劃製程安全資訊、勞工參與、機械完整性，實際內容依座談共識及後續規格辦理 | 本計畫工作項 |
| 劣化比對 | 得連本署劣化機制查詢資料庫，不代評分 | API 571；本署資料庫 |

**表六　數位化格式規定**

| 項目 | 格式規定 |
| --- | --- |
| 共用索引 | 以附件一為填報起點，製程、設備、化學品分表記載 |
| 設備 | 必填所屬製程；後續各項要求選既有編號 |
| 化學品 | 代號加製程分列；安全資料表集中建檔後以代號連結 |
| 評估 | 先選製程，再選該製程下之設備及化學品 |
| 圖資 | 除上傳檔案外，須填圖號、版次、所屬製程及涵蓋設備 |
| 裝卸 | 不另設運輸表；車牌寫在佔用紀錄 |
| 第一次填報 | 先完成三張核心表所需資料，再填各項製程安全管理要求 |
| 劣化資料庫 | 得比對腐蝕劣化機制，不得代替製程危害控制措施之風險評分 |

## 4.5.5　建立機械完整性

機械完整性之填報規格已納入手冊第十一章；網站功能將於架構確立並完成座談後再行設計。事業單位得運用本署「設備管線劣化機制查詢資料庫」比對腐蝕劣化機制，不得以查詢結果代替風險評分。

**表九　機械完整性填報項目**

| 項目 | 規定 |
| --- | --- |
| 設備分類清單 | 與設備總表同一編號及類型，內容物與對應表相同 |
| 安全關鍵清單 | 另列檢查頻率及程序書編號，不能以分類清單代替 |
| 檢查紀錄 | 含設備編號、日期、執行人員、方法及結果之檢查或測試紀錄 |
| 腐蝕劣化 | 得自對應表延伸材質、內容物、殘留；人員確認後得查詢劣化資料庫 |
| 程序及檢測 | 書面程序及檢測、保養、入廠檢驗紀錄為附件，並註明設備編號 |
