## 1. 主檔

| 資料 | 表 | 主鍵 | 說明 |
| --- | --- | --- | --- |
| 場所 | `site` | site_id | 甲類工作場所 |
| 部門 | `department` | dept_id | 操作或維護單位，可有上級部門 |
| 製程 | `process` | process_id | 必填 operating_dept_id |
| 設備 | `equipment` | equipment_id（位號） | 必填 process_id、maint_dept_id。所在區域不在此列必填 |
| SDS | `sds` | sds_id | 檔案路徑只存在這張表 |
| 化學品成分列 | `chemical` | (cas, process_id) | 手冊的 chemical_component。必填 sds_id、h_codes |
| 化學品選取 | `chemical_cite` | (cas, process_id) | 同一 CAS 若有多列混合物，後續單元只選這一筆 |
| 廠區區域 | `area` | area_code | |
| 對應表 | `pec_map` | (process_id, equipment_id, cas) | 實際存在的製程－設備－化學品關係。不要一次產生該製程全部配對 |
| 建造材料 | `equipment_material` | equipment_id | 表1.6-1。材質類別＋規格名稱；第八章帶出，見第 6 節 |

細表不要複製主檔的名稱欄。

## 2. 外鍵與關聯

- `chemical.sds_id` 對到 `sds`。同一 CAS 出現在兩個製程時，兩列必須指向**同一筆** SDS。
- 後續單元選化學品時選 `chemical_cite`，不要把某一列混合物當成唯一物質。
- 設備所在區域用 `area_equipment`（多對多）。`equipment.area_code` 只給廠區示意圖用，可空。
- 區域與製程、區域與化學品同樣用 `area_process`、`area_chemical`。
- 對應表列的 `equipment.process_id` 必須等於該列的 `process_id`。有 CAS 時，`chemical_cite` 必須已存在。不可把 A 製程的化學品掛到 B 製程的設備（示範廠：鹽酸不得掛到 T-101）。
- HAZOP 節點的設備與化學品必須已出現在該製程的對應表。
- `safeguard.sop_id`、`training_course.sop_id`、`prompt_event` 的製程／設備已宣告外鍵。

## 3. 不要做

- 在化學品表存放 SDS 檔路徑（本 demo 已無 `chemical.sds_file`）。
- 一鍵產生該製程全部設備 × 全部化學品。
- 細表手打設備名、品名、課室名。
- 代填嚴重度、可能性，或串接劣化資料庫代替人員評分。
- 把十四項收成三張法定表。

## 4. 示範廠資料（seed）請保留這些例子

- 甲苯 `108-88-3` 在 P-TANK 與 P-LOAD 共用 `SDS-TOL-001`。
- P-ACID、PL-201、鹽酸 `7647-01-0` 為一組；不得配到 T-101。
- P-TANK 四台設備都有對應表列；ESD-101 可聲明無製程化學品。
- PSV-101 故意不列入 HAZOP，用來檢查涵蓋是否完整。

## 5. 正式庫可再補（不影響本 demo 交件）

下列目前用填報列或字串欄處理，正式庫可改成正規外鍵，但不要另建一套名稱主檔：

- 表1.1／1.2：選 `chemical_cite` 後，由人員填用量與物化確認（現在在 `filing_row`）。
- 表1.3 方塊、表1.11 合格證獨立列。
- `change_request.target_pk` 改成可空的 process_id、equipment_id、cas 外鍵。
- `incident.cas` 改成對到 `chemical_cite`。

手冊表8.0-1 的劣化查詢條件（介質發生條件、保溫、銲道等）不寫入填報庫；那些在本署查詢頁勾選。

## 6. 表1.6-1 與第八章機械完整性

建造材料只填一次，存在 `equipment_material`（表1.6-1）：

| 欄 | 用途 |
| --- | --- |
| material_category | 本署劣化機制查詢的材質選項，例如碳鋼(CS)、300系不銹鋼 |
| material | 規格名稱，例如 SS316L、CS A283 |
| spec | 設計規範及標準 |

設備清單與表8.1-1 的「材質類別／選用材質」由這張表帶出，第八章不要再開欄讓人另填。規格名稱不能直接當查詢條件，必須先歸入材質類別。

連線查詢前還要有表1.5 操作溫度與該設備內容物。三者齊全後，人員才到本署頁勾選介質、保溫等。查詢結果由人員確認後填入損壞機制；系統不代填、不把查詢結果寫進填報庫。
