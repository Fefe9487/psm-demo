# PSI 填報順序與數量來源

2026-11-09 調整第 1 章的填報流程，解決化學品清單與表 1.1 各自填量、可能不一致的問題。

1. 表 1.0-4 建立製程、SDS、CAS、名稱、製程功能、相態、水溶液別，以及混合物成分與重量百分比。此處不再輸入純物質操作量、混合物總量或自訂換算式。
2. 表 1.1 依製程＋SDS＋純物質／混合物來源＋地點，填寫最大存量與平均每月使用量。混合物的整體存量只填一次；同來源不同地點可分列，同來源同地點重複儲存會更新原列。
3. 表 1.1 依成分比例上限計算純物質量與成分月用量，並依 CAS＋製程自動彙總。表 1.2 及報表讀取同一份來源存量與當前成分，不再接受另外手填的 CAS 最大存量。

純物質以 100% 計算；混合物以「最大存量 × 成分重量百分比上限 ÷ 100」換算。體積比或重量／體積比須先換算，否則成分量保留待確認。月用量另外換算，不拿來代替最大存量。零是有效的已知量；空白、負數、非有限數字或帶體積單位的數值不能當作有效最大存量。

## 舊資料

既有 chemical.attributed_qty、mix.total_kg 及舊版表 1.1 的獨立數值保留。舊版化學品／混合物數量可回填為待確認參考，舊版表 1.1 的 CAS 彙總則收於核對區，不自動分配到 SDS 或地點，也不與新量相加。

未確認的來源不視為零，不宣告已完成加總。任一來源尚未確認，CAS 彙總顯示「待確認」，另可顯示已確認部分。表 1.2 的判定使用既有相態與水溶液別規則；本次改動數量來源，沒有修改門檻規則。

來源存量存於既有 filing_row 的 `1.1-source` 區段，由 `psm/chemical_stock.py` 驗證及計算。表單入口為 `/wizard/1/stock`。來源身分改變後須重新選取、確認；不存在於目前化學品清單的來源不納入計算。

## 材質順序

設備建檔、表 1.6-1 及材料資料頁均先勾選建造材質類別，再填選詳細規格。詳細規格的建議來自已登錄設備，依所選類別篩選；沒有建議時可自行輸入。這不是標準規格或材質適用性認證。既有單選資料仍能回填，多類別以既有文字欄位儲存。

## 驗證

自動測試涵蓋單一混合物多成分、同 CAS 不同 SDS、同來源多地點、重複儲存、編輯、刪除、零量、未知量、無效數字、來源識別、比例更新、表 1.2 與報表連動。測試使用獨立資料庫。

完整回歸結果：187 passed in 255.44s；另補充體積比例不能直接當重量百分比的測試，亦通過。JavaScript 語法與 Git 差異檢查通過。

瀏覽器驗證涵蓋實際儲存與再次編輯、化學品建立後自動更新表 1.1、材質類別與規格連動、既有資料回填，以及桌面／手機排版。連續儲存回到同一網址時強制更新頁面，避免數值已存入卻仍顯示舊列表。
