# Demo 修正：首次填報要一步步導引（精靈）

給實作 Agent。先讀 `docs/2026-08-21-DEMO-交給Agent.md` 與開站 SPEC。本檔**覆寫**先前「首頁改廠區圖」的優先順序：廠區圖是填完之後的檢視，不是首次客戶的主路徑。

開頭請貼：

> 最重要的使用者是**第一次填報的客戶**。他要明確的一步步導引：這一頁要填什麼、為什麼、沒做完不能跳下一步。現況側欄加表格是編輯器；只放廠區圖也不夠，空白廠沒東西可點。硬規則仍以開站 SPEC 為準。資料表後台可留，但打開系統預設必須進精靈。

---

## 問題

側欄十四項＋每頁表格／新增表單＝後台編輯器。有 seed 時像在改別人填好的庫。  
首次客戶需要的是：**我現在在第幾步、這步做完才能做下一步、選單是系統帶出來的不是我自己發明名稱。**

---

## 主路徑：首次填報精靈（必做）

進系統預設 `/wizard`（或 `/` 直接進精靈）。上方固定：步驟列＋進度（例如 3／14）＋「上一步／下一步」。

每一步同一版型，不要換成另一套後台表：

| 區塊 | 內容 |
|---|---|
| 現在哪一步 | 步驟編號＋短標題（例：第 4 步，建立製程） |
| 為什麼 | 兩句話，對應該步蒐集目的（不是法規條文堆疊） |
| 這一頁只要做 | 最多一組任務：新增一列、或上傳、或從已有清單勾選 |
| 已完成 | 本步已有的列，用卡片列出（編號＋名稱），可刪除／更正 |
| 還不能往下 | 紅字寫缺哪一項必填；「下一步」disable |
| 下一步會用到 | 一句：例如「下一步選設備時，只能選你現在建立的製程編號」 |

步驟順序對齊手冊附錄 A，**可合併畫面，不可顛倒**：

1. 場所（名稱、範圍、申請義務人、勞工人數）  
2. 部門＋組織系統圖上傳  
3. 送審第二章計畫／規章／制度：每項一個上傳槽＋文件名、日期（不拆全文）；無承攬等可勾「本場所無此情形」  
4. 製程：一筆一筆新增；操作權責**只能選步驟 2 的部門**  
5. 廠區位置圖：上傳＋區域代碼；控制室、消防、各區人數  
6. 設備：所屬製程、維護部門、所在區域都是下拉；類型為動力來源才出現泵浦／氣動；有緊急停車系統才出現方案＋動作設備（動作設備僅該製程）  
7. SDS 資料庫：SDS 代號＋化學品代號＋版次＋附件（可先建庫）  
8. 化學品：製程下拉＋化學品代號＋角色；SDS 下拉僅該化學品代號已有之安全資料表；禁止在化學品列直接上傳 SDS  
9. **對應表**：只新增實際設備－化學品關係；帶入 h_codes、材質；勾可能殘留；確認或填不適用理由。本步觸發寫死提示  
10. P&ID：上傳＋圖號版次＋涵蓋設備（多選，僅該圖所屬製程的設備）  
11. 製程安全資訊掛載：存量、上下限、材料、釋壓、連鎖（對象都是已有 ID；材料與對應表一致）  
12. HAZOP：先強制選製程 → 下拉只出來自對應表的設備與化學品 → 進入節點列出 pha 提示 → 偏離／後果／人點 5×5（S、L 空白不預填）→ 涵蓋檢查  
13. 機械完整性：與設備同一編號；列出 mi 提示；不連劣化庫  
14. 其餘單元：能選 ID 的選 ID；計畫已於步驟 3 上傳的註明參閱；無則聲明  
15. 預覽申報報告 → 產出  

核心資料表與該製程對應表未完備前，HAZOP 的評分與「評估完成」關閉，並寫明缺哪一張表。

## 兩種進場（不要只有 seed）

| 入口 | 給誰 |
|---|---|
| **開始首次填報**（預設） | 空白場所，從步驟 1 走完。這是要示範給客戶看的主路徑 |
| 查看示範廠 DEMO-SITE | 現有 seed，用來對照「填完長這樣」；不要當首屏唯一狀態 |
| 資料表（摺疊） | 給已會填的人改一筆；不是首次導引 |

首次路徑不要一進來就看到 T-101 已填滿、再給一排空白表單。

---

## 互動要做到哪裡（精靈裡，不是另開編輯器）

- 每步只問這步的事；不要一頁二十個欄位  
- 後步的下拉＝前步已存的 ID（製程、部門、區域、設備、化學品代號、SDS 代號、對應表列）  
- 選錯製程就看不到別製程的設備（HAZOP、ESD 動作、P&ID 涵蓋清單、對應表皆同）  
- 最後一步之前給一頁「你已經建立：製程 n、設備 n、化學品 n、對應列 n」再進 HAZOP  
- 不要算裂化速度、不要預填 S／L、不要把十四項當十四個主選單當首屏  
- 上傳計畫類：選檔＋名稱＋日期即過關，不逼填程序正文  
- 步驟列可回看已完成步；未解鎖的步點了要提示「請先完成第 n 步」  
- 最後一步之前給一頁「你已經建立：製程 3、設備 6、化學品 2、SDS 1」再進 HAZOP  
- 廠區示意圖：有區域與設備之後，可在步驟 5／6 或精靈結束後當**檢視**，點設備看到 JOIN 資料。空白時不要把廠區圖當首頁。

---

## 不要做

- 不要把十四項當十四個主選單當首屏  
- 不要只有廠區圖、沒有逐步導引  
- 不要讓首次客戶一進來就掉進已填滿的 seed 編輯頁  
- 不要另造核心資料表；不要手打設備名／品名／課室名  
- 不要 OCR、簽核流、程序書全文、規則全集、自動評分或自動停機

## 驗收（首次客戶路徑）

- [ ] 選「開始首次填報」後，畫面是步驟 1／場所，有「為什麼」和「下一步」disable 直到必填齊  
- [ ] 未建部門前，製程步的操作權責下拉是空的或不可進  
- [ ] 未建製程前，進不了設備步（或下一步 disable＋說明）  
- [ ] HAZOP 步未選製程時設備不可選；選 P-TANK 選不到 LA-101，也選不到 PL-201  
- [ ] 對應表未完成時不能評分，畫面上寫出缺什麼  
- [ ] 開 PL-201 節點看得到寫死提示，S／L 空白  
- [ ] 計畫類步驟：上傳檔即可過，不出現程序書大表  
- [ ] 走完可產出報告；示範廠路徑仍可打開看填完的例子  
- [ ] 開站 SPEC／原 DEMO 清單硬規則仍要過
