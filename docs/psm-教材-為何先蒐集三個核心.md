# 為什麼 PSM 一開始要蒐集製程、設備、化學品

給上課或內部說明用。法規條文仍以《製程安全評估定期實施辦法》與送審手冊為準；這份只解釋**為什麼先有三個核心，14 項才填得下去**。逐表對應見 [psm-三原-14項細表對照.md](./psm-三原-14項細表對照.md)。

---

## 第一堂：場所是一個次元

一般入門會先背 14 項 PSM。比較容易記住的起點是：一個甲類場所就是一個**次元**。真正在運轉的是次元裡的三件事，而且它們一直在交互。

| 宇宙學 | 在廠裡 | 主檔 |
|---|---|---|
| 次元 | 這個甲類場所 | 案件／場所 |
| 空間 | 東西在哪：槽、管、閥、連鎖。P&ID 是空間的圖 | 設備 |
| 時間 | 物質在空間裡應該怎麼走：連續或批次、開車、正常、停車、安全上下限 | 製程 |
| 物質 | 佔空間、沿製程移動、會反應的東西 | 化學品（用 CAS 認明） |

沒有單獨安全的物質。氨在鋼瓶倉庫、氨在反應槽、氨走錯管線進酸槽，是三種不同的交互，不是同一格 SDS 可以代表的「安全」。

所以蒐集不是為了先有三張清單好看，而是為了先把這個小宇宙的度規建起來：

1. 先有製程：時間怎麼走。  
2. 設備掛上製程：空間落在哪一段時間裡。  
3. 化學品掛上製程（CAS）：物質進入這個時空。

這三筆還沒齊，表 3.1-2 的「設備名稱及編號」只是在造字，檢查表的「對象」對不到現場，HAZOP 節點也沒有可以指的空間。14 項會變成 14 本互不相干的作業。

**課堂一句話：** 危害不是表上的一格，是同一個次元裡時間、空間、物質碰在一起之後的產物。PSM 要管的是這個交互，不是管交卷。

## 黑板例子：A-101

設製程 P1（連續、有過壓），設備 A-101 是反應槽，槽裡有物質（某 CAS）。

問學員：現在「安全」指的是哪一層？

- 只寫化學品危害 → 只看到物質，沒有空間與時間。  
- 只寫 A-101 已檢查 → 只看到空間被保養，不知道它在哪段製程、裝什麼。  
- 三筆都掛在一起 → 才問得出：這個物質、在這個槽、走這條製程時，上限是多少、釋壓在哪、SOP 怎麼停、偏了會怎樣。

再問：若把 A-101 的安全閥換掉，改的是哪一原？  
空間被改了。物質與製程可能沒改，但**交互變了**：上下限、釋壓資料、檢查、用這層防護撐住的危害分析節點、相關 SOP 與訓練，都要拿出來確認。不是只在「設備變更」那一格打勾。

## 第二堂：14 項是這個宇宙裡的職能

三個核心建好之後，14 項才有對象。它們不是另一個世界，是同一套時空物質上的不同工作。

| 職能 | 在三原交互裡做什麼 |
|---|---|
| 製程安全資訊 | 把空間、時間、物質量清楚（圖、上下限、存量、材質） |
| 危害分析 | 見第三堂 |
| 標準作業程序 | 規定時間該怎麼走 |
| 教育訓練 | 誰會走這段時間 |
| 機械完整性 | 空間是否還在、防護是否真的有效 |
| 變更管理 | 三原之一被改時，交互是否仍成立 |
| 啟動前安全檢查 | 改完的空間／時間，在引入物質前是否可走 |
| 緊急應變 | 三原交互失控之後怎麼辦 |
| 其餘（勞工參與、承攬、動火、事故、稽核、機密） | 次元職能：誰能進出這個宇宙、看得到量測、改得留下證據 |

送審表是掛件：表 3.1-2、3.1-6、3.8-1 掛設備；PFD、SOP、HAZOP 掛製程；危害檢核與存量掛化學品＋製程。同一設備在不同表必須是同一個編號。

**課堂一句話：** 先有宇宙，才有法律要求的儀表。儀表讀數要指回同一個空間、同一段時間、同一種物質。

## 第三堂：偏離是開假設世界；變更是真的改了宇宙

危害分析（HAZOP 等）不是再填一張與主檔無關的表。它是在已經量好的時空物質上，**只擾動其中一原**，看另外兩原會不會塌、現有防護還在不在。

- 擾動時間：流量高、溫度低、步驟做錯  
- 擾動空間：閥失效、破裂、連鎖不動作  
- 擾動物質：加錯料、不相容、濃度偏  

每個假設世界問三個問題：描述（三原）對不對？防護有沒有效？哪一項管理沒到位（沒有 SOP、沒有檢查、沒有訓練……）？防護無效，就補一層——而且補的那一層必須回到主檔：新的閥要成為設備，新的步驟要成為製程上的程序。只寫在工作表裡的防護，這個宇宙裡不存在。

變更是另一回事：不是假設，是宇宙真的被改了一筆（換閥、換料、改步驟）。這時要把掛在被改那一原上的紀錄一次拿出來確認，並把相關的假設世界再走一遍。只改設備列、不重看用到這層防護的分析節點，等於現場已經是新宇宙，紙上還停在舊的。

**課堂一句話：** 分析是假設世界；變更是真的改宇宙。兩者都要問同一件事：三原的交互還安不安全。

## 收束：對回送審草案

甲類初次送審看起來像在填 14 章。填的順序其實是：

1. 蒐集三個核心（製程、設備、化學品／CAS）  
2. 各細表掛上編號，不另造名稱  
3. 14 項都要交；沒有該情形則聲明或空白表  
4. 報告是把已掛好的內容依手冊章節投影出來  

若學員問「為什麼不先把附表一填完再補清單」：因為附表一的每一格都在描述三原交互。沒有核心，格子裡的字對不到現場，交出去的是文件，不是製程安全。
