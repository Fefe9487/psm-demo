## 0. 設計構想（demo 必須照這個做）

十四項仍是十四項，不是解構成三張表。先建製程、設備、化學品當共用索引；引導填完對應表（製程安全資訊主表）；再用 **SPEC §10 寫死規則** 依既有列提示。

| 階段 | Demo 要做 | Demo 不做 |
|---|---|---|
| 對應表 | 只記實際關係；帶入危害說明、材質、是否可能殘留 | 全製程設備×化學品排列組合 |
| 製程危害控制措施 | 下拉來自對應表；列出 pha 提示；S、L 空白由人點 | 代評分、預填矩陣 |
| 機械完整性 | 同一編號；列出 mi 提示 | 連劣化庫、算裂化／腐蝕速度、規則全集 |

優點是人最容易錯的「各表各叫一名」改由編號勾稽。完整專家規則屬後續投資，本 demo 只證明路徑。三張核心表不取代附件一十二項。

## 1. 要做出什麼

一個可操作的垂直切片 demo（本機即可）：

1. 引導式填報：場所 → 部門與組織圖 → 送審第二章計畫類附件 → 製程 → 平面配置結構化 → 設備 → SDS 資料庫 → 化學品 → 代號表連結 → **對應表** → 製程安全資訊其他掛載 → HAZOP（含寫死提示）→ 機械完整性提示 → 其餘單元 → 評分與報告
2. 十四項都有頁面（深度見第 5 節）；送審第二章十二項在前段（計畫上傳、化學品／危險性機械／平面圖用核心資料表投影）
3. 一鍵產出「甲類送審／報備」報告（HTML 可印 PDF 即可）
4. 預載第 4 節 seed，打開就能點，不必從空白廠開始

技術不限。關聯式資料庫（SQLite 可）。畫面 JOIN 顯示名稱；子表禁止複製父表名稱。

## 2. 硬規則（違者不算完成）

- 核心資料表為製程、設備、化學品。維護權責部門是組織資料表（獨立 PK），不列入核心資料表。SDS 資料庫以 SDS 代號為獨立 PK，經代號表連到化學品列。對應表是掛載表。以上都不是第四份核心資料表。
- 化學品表禁止 `sds_file`。同一化學品代號之多個製程列應連同一現況 SDS 代號。代號表之化學品代號必須等於 SDS 庫該筆（化學品代號即 CAS No.）。化學品列必填 `h_codes`。
- 沒有運輸主檔。車牌只寫在裝卸佔用列。過境未裝卸不建主檔、不評分。
- 設備必填：`所屬製程編號`、`維護權責部門編號`。製程必填：`操作權責部門編號`。操作權責與維護權責可以不同。
- **對應表**：只新增實際存在之設備－化學品關係；禁止一鍵產生該製程全部設備 × 全部化學品。該製程每台設備至少一列（有化學品或聲明無）之前，不得開放該製程風險評分。
- HAZOP：先選製程編號，再只能選對應表上的設備與化學品代號。存檔檢核 `設備.所屬製程編號 = 評估.製程編號`，且能對到對應表。進入節點須列出 SPEC §10 命中之 pha 提示；**不得預填 S、L**。
- 機械完整性頁與設備同一編號，列出 mi 提示。不連劣化資料庫、不算裂化速度。
- 細表只能選 ID，不能手打設備名／品名／課室名。
- 圖檔可佔位；圖號、版次、所屬製程、涵蓋設備清單必填。無結構化登錄不得供 HAZOP 勾該圖。
- 設備類型八選一（完整名稱，對齊機械完整性六大類＋裝卸／其他）：壓力容器與儲槽、管線系統、釋放及排放系統、緊急停車系統、控制系統、動力來源、裝卸及輸送、其他。類型為動力來源時必填動力型式：泵浦／氣動／其他。操作分類另欄：液體／氣體／後段處理。控制系統與緊急停車系統分列。
- 緊急停車方案是掛載表，不是主檔。有 ESD 設備而無方案或無動作設備清單 → 標示不完備。
- 核心資料表與該製程對應表未完備前，不得開放製程危害控制措施風險評分。
- 程序方面全部空著：不寫程序書正文、不做簽核／代理人／派工。送審第二章之計畫／規章／制度只留附件槽（可用空白佔位檔）。每項保留「程序編號／附件」空欄即可。
- 畫面用語用十四項單元名稱與「附件一」；不要對使用者寫「附表一」至「附表十四」。

## 3. 明確不做

- 程序手冊全文、七階段 SOP 正文、MI／MOC／PSSR／應變計劃全文
- 審核流程、權限系統（單機單使用者即可）
- P&ID OCR、劣化資料庫連線、裂化／腐蝕速度計算
- 專家規則全集（只做開站 SPEC §10 那一條寫死規則）
- 機械完整性腐蝕迴路、檢測點整套
- 以完成率代替安全狀態
- 另開一套與主檔脫鉤的風險分數
- 把十四項收成三張法定表，或宣稱取代附件一十二項

| 對象 | 值 |
|---|---|
| 場所 | `DEMO-SITE` 示範甲類工作場所（溶劑儲存及裝卸）；勞工人數 12 |
| 部門 | `D-OPS` 操作課；`D-MAINT` 保養課；組織系統圖 1 個佔位附件 |
| 送審第二章計畫 | 項次 3、5–11 各一佔位附件（檔名即可）；項次 9／10／11 註明其後附表參閱 |
| 製程 | `P-TANK` 儲槽（連續、操作 D-OPS）；`P-LOAD` 裝卸（批次、裝卸單元）；`P-SCRUB` 後段處理單元；**`P-ACID` 酸液輸送（連續、操作 D-OPS）** |
| 設備 | `T-101` 儲槽（壓力容器與儲槽、液體、P-TANK、維護 D-MAINT、AREA-A、**是危險性設備**、合格證 DEMO-PV-001）；`P-101` 泵浦（動力來源／泵浦、P-TANK）；`PSV-101` 安全閥（釋放及排放、P-TANK）；`ESD-101`（緊急停車系統、P-TANK）；`LA-101` 鶴管（裝卸及輸送、P-LOAD、AREA-B）；`S-201` 洗滌塔（釋放及排放、後段處理、P-SCRUB）；**`PL-201` 管線（管線系統、液體、P-ACID、維護 D-MAINT、AREA-A、材質碳鋼）** |
| 化學品 | 甲苯，化學品代號 `108-88-3` × `P-TANK`（儲存，h_codes 如 H225）；同一代號 × `P-LOAD`（卸收）；**氯化氫水溶液成分 `7647-01-0` × `P-ACID`（原料，h_codes 含 H314、H335）** |
| SDS | `SDS-TOL-001`，化學品代號 `108-88-3`（CAS No.），佔位附件一份；上列兩筆甲苯都連此 SDS 代號（現況版）。**`SDS-HCL-001`，化學品代號 `7647-01-0`，混合物名稱酸洗液，佔位附件一份，連 P-ACID 列** |
| 對應表 | P-TANK 各設備與甲苯之實際列（至少 T-101、P-101）；P-LOAD × LA-101 × 108-88-3；**P-ACID × PL-201 × 7647-01-0，材質碳鋼，may_remain＝true，review_notes 可由規則預填「材質條件不相容；停車未排淨」，人員確認**。禁止把 P-ACID 化學品配到 T-101。 |
| 提示 | 開 PL-201 的 PHA 節點與 MI 頁時，列出 SPEC §10 `R-H314-CS-REMAIN`；S／L 空白。甲苯列不應命中此規則。 |
| 圖資 | `PID-TANK-001` Rev.B，製程 P-TANK，涵蓋 T-101、P-101、PSV-101、ESD-101；廠區 `AREA-A`（控制室否、作業勞工 8）、`AREA-B`（裝卸、作業勞工 4）；另 `AREA-CCR` 控制室、`AREA-FIRE` 消防；至少一處集合點 |
| ESD 方案 | `ESD-SC-TANK-01` 所屬 P-TANK，系統設備 ESD-101，動作至少含 P-101 |
| 評估 | `PHA-2026-001` 掛 P-TANK；至少 2 個節點（T-101 液位過高、P-101 出口閥誤關）；防護選設備或方案編號，禁止純文字 |
| 矩陣 | Demo 鎖定 5×5（嚴重度、可能性 1–5）。可接受線自行寫死一條並在報告封面載明 |

| 裝卸佔用 | 1 筆掛 LA-101 + P-LOAD + 108-88-3 + 車牌，**不新增設備列** |

| SOP | 清單各 1 筆掛 P-TANK／P-LOAD／P-SCRUB，正文空 |
| 聲明 | 無承攬；無動火（或動火 1 筆掛設備編號，對象不得只寫廠區名）；事故近五年 0 件＋空白格式；符合性稽核「尚未第一次」＋預定日期 |

## 5. 十四項深度（申報有、程序空）

| 單元 | 名稱 | Demo 要做到 |
|---|---|---|
| 1 | 製程安全資訊 | 三張核心表＋對應表＋圖資結構化＋存量、上下限、材料、釋壓、連鎖；危害說明帶入後不再另勾火災／腐蝕／毒性 |
| 2 | 製程危害控制措施 | HAZOP（下拉來自對應表）、寫死 pha 提示、簽認摘要（可 seed 人名）、會議 1 筆、改善列、事故納入（0 或虛驚）。S、L 由人點，不預填 |
| 3 | 勞工參與 | 1 筆活動掛製程；計畫附件空 |
| 4 | 標準作業程序 | 清單掛製程；七階段正文空 |
| 5 | 教育訓練 | 課程掛製程；可 1 筆已訓 |
| 6 | 承攬管理 | 聲明無承攬＋空白清冊 |
| 7 | 啟動前安全檢查 | 1 筆掛設備或變更所涉製程；程序空 |
| 8 | 機械完整性 | 分類清單與主檔同一編號及類型；安全關鍵；ESD 方案；1 筆檢查；列出 mi 提示。腐蝕迴路、裂化速度、劣化庫連線不做 |
| 9 | 動火許可 | 聲明或 1 筆掛設備編號 |
| 10 | 變更管理 | 1 筆必填被改 PK |
| 11 | 事故調查 | 0 件＋空白格式，或 1 筆虛驚掛製程 |
| 12 | 緊急應變 | 組織摘要、集合點區域代碼、1 筆演練掛製程及後果；計劃全文空 |
| 13 | 符合性稽核 | 尚未第一次＋預定計畫；查核表骨架對十四項 |
| 14 | 商業機密 | 清單指回製程／圖號；編號仍可選；協議附件空 |

每一項畫面上保留「管理程序」空卡，報告對應節印：「本示範未納入程序書全文。」

## 6. 報告長什麼樣（產出物）

不是十四份各自上傳的 PDF。由資料庫組一份文件，目錄固定：

1. 封面：事業單位、場所、申請義務人（seed）、評估基準日、矩陣版本
2. 送審第二章：組織圖附件名；計畫／規章／制度附件清單；危害性化學品由核心資料表列出並顯示所連 SDS 代號；危險性機械由 T-101 投影；平面圖五項標示由區域＋設備＋存量投影
3. 主檔摘要：製程／設備／化學品 JOIN（名稱由關聯帶出）；另附對應表（只列實際關係）
4. 圖資索引：圖號、版次、涵蓋設備、區域代碼
5. 第三章 3.1–3.14：每節三段——程序（空或註明參閱第二章）、執行結果（有列才印；聲明項印「本場所無此情形」）、使用表單／附件清單
6. 製程危害控制措施核心：HAZOP 工作表（節點、設備編號、化學品代號、偏離、後果、防護、提示事項、S、L、等級）。提示與分數分欄，不得把提示當成分數
7. 附錄 A 自我檢核：有結構化資料的題勾「已建立」；程序題一律「本階段從缺」；第二章計畫題勾「已上傳附件」

表號對送審手冊即可（3.1-x、3.2-x），欄位可精簡，語意不可改。

## 7. 驗收（全部要過）

- [ ] 無 `process_id` 的設備無法存檔
- [ ] HAZOP 未選製程時設備欄關閉
- [ ] 選 P-TANK 後選不到 `LA-101`
- [ ] 設備表沒有「製程名稱」「部門名稱」實體欄；部門改名不必改設備列
- [ ] P&ID 只上傳檔、未填圖號／涵蓋設備時，HAZOP 不能勾該圖
- [ ] 動力來源未填泵浦／氣動無法存檔
- [ ] ESD 無方案或無動作清單時，該製程緊急停車標示不完備
- [ ] 裝卸佔用寫車牌不新增 Equipment
- [ ] 主檔未完備前不能把評估標示完成、不能評分
- [ ] 改善若只勾「已改善」而未指到主檔 PK，不得關閉
- [ ] 十四項報告都有對應章；程序節為空而非假造程序全文
- [ ] 報告裡的 T-101、108-88-3 與畫面上同一套 ID
- [ ] 送審第二章計畫類有附件槽；報告第二章不另出現手打的設備名／品名清單
- [ ] Chemical 無 sds_file；`SDS-TOL-001` 一份附件，P-TANK 與 P-LOAD 兩列甲苯都連此代號
- [ ] 代號表把丙酮 SDS 掛到甲苯列時無法存檔
- [ ] 對應表不能一鍵產生該製程全部設備×全部化學品；P-ACID 未對應完前不能評該製程
- [ ] 選 P-TANK 後選不到 `LA-101`，也選不到 `PL-201`
- [ ] 開 PL-201／7647-01-0 節點時出現「材質條件不相容；停車未排淨」（或 SPEC §10 同等文案），S／L 仍空白
- [ ] 甲苯節點不出現該條酸－碳鋼提示
- [ ] 提示標不適用但未填理由時，不得標為已處理
- [ ] 畫面上無「附表一」…「附表十四」；可用單元名稱與「附件一」
- [ ] 報告含對應表與提示事項，且未把提示寫成風險分數

## 8. 填報順序（畫面可合併，不可顛倒）

見開站 SPEC 第 5 節：場所 → 部門 → 送審第二章計畫類 → 製程 → 位置圖結構化 → 設備（含 ESD 方案）→ SDS 資料庫 → 化學品 → 代號表 → **對應表** → P&ID 結構化 → 製程安全資訊其他掛載 → 先選製程再 HAZOP（含 pha 提示）→ 機械完整性提示 → 其餘單元。
